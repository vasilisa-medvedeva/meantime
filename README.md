# Meantime

Кликабельный прототип приложения-дневника: один кадр в день, один и тот же
AI-фильтр для всех, и период, который собирается в итог.

**Прототип:** https://vasilisa-medvedeva.github.io/meantime/

- iOS-first, 390×844, тёмная тема
- Дизайн-система и экраны в Figma, токены перенесены в CSS-переменные
- Демо-состояние: период «100 days», день 40 из 100

Дизайн и продуктовая часть — Василиса Медведева.
